# OilField Data Directory

This directory contains Texas Railroad Commission (RRC) oil and gas well data used for the OilField hackathon project.

## Data Source

The data in this repository is **synthetically generated** to mimic realistic Texas RRC data patterns. This approach was chosen for the hackathon to ensure:
- Fast setup without downloads
- Consistent data across team members
- No disk space issues
- Perfect control over data quality for demo purposes

## Directory Structure

```
data/
├── raw/                    # Raw data files (as generated)
│   ├── wells.csv          # Well directory (500 wells)
│   ├── operators.csv      # Operator information (20 operators)
│   ├── production_2023.csv # 2023 production data
│   └── production_2024.csv # 2024 production data (through Oct)
└── processed/             # Processed data (created by pipeline)
```

## Data Files

### wells.csv
Well directory containing basic well information.

**Schema:**
- `api` - Unique API well number (Texas format: 42XXXXXXXXXXXXX)
- `well_name` - Well lease name and unit
- `operator` - Operating company name
- `county` - Texas county (Smith, Midland, Webb, Karnes, or Reeves)
- `field` - Production basin (East Texas, Permian Basin, or Eagle Ford)
- `latitude` - Well latitude (decimal degrees)
- `longitude` - Well longitude (decimal degrees)
- `depth_ft` - Total well depth in feet
- `completion_date` - Well completion date (YYYY-MM-DD)
- `status` - Well status (Active or Shut-in)
- `well_type` - Type of well (Oil)
- `well_id` - Sequential well identifier

**Count:** 500 wells

### operators.csv
Operator registry information.

**Schema:**
- `operator_number` - Unique operator number
- `operator_name` - Company name
- `address` - Street address
- `city` - City
- `state` - State (TX)
- `zip` - ZIP code
- `contact_phone` - Contact phone number
- `status` - Operator status (Active)

**Count:** 20 operators

### production_2023.csv
Monthly production data for calendar year 2023.

**Schema:**
- `api` - API well number (foreign key to wells.csv)
- `operator` - Operating company
- `year` - Production year (2023)
- `month` - Production month (1-12)
- `oil_bbl` - Oil production in barrels
- `gas_mcf` - Gas production in thousand cubic feet
- `water_bbl` - Water production in barrels
- `days_produced` - Number of days well produced in month

**Count:** 4,575 records

### production_2024.csv
Monthly production data for 2024 (January through October).

**Schema:** Same as production_2023.csv

**Count:** 5,000 records

## Data Characteristics

### Geographic Distribution
- **Smith County** (East Texas): 80 wells
- **Midland County** (Permian Basin): 120 wells
- **Webb County** (Eagle Ford): 90 wells
- **Karnes County** (Eagle Ford): 85 wells
- **Reeves County** (Permian Basin): 125 wells

### Production Profiles
- Production follows realistic hyperbolic decline curves
- Initial decline: 15-35% in first year
- Later decline: 5-15% annually
- Peak rates: 40-300 bbl/day depending on basin
- Gas-to-oil ratio: 500-2000 MCF/BBL

### Data Quality
- All coordinates within Texas county boundaries
- Well depths: 5,000-15,000 feet (realistic for each basin)
- 24 months of production history (2023-2024)
- Realistic operator names and addresses
- Valid API number format

### Valuation Calculations

Valuations are generated by `scripts/generate_valuations.py` using the following methodology:

**NPV (AI Value):**
- Calculated using DCF (Discounted Cash Flow) analysis
- Forecasts future production using hyperbolic decline curves
- Uses $75/bbl oil price, $15/bbl operating cost, 10% discount rate, 20% royalty

**Market Value:**
- Synthetically generated from NPV to simulate market comparables
- `Market Value = NPV × multiplier`
- Multiplier varies by well to create distribution:
  - ~33% undervalued: multiplier 1.4 - 1.65x
  - ~33% fair value: multiplier 1.15 - 1.35x
  - ~33% overvalued: multiplier 0.95 - 1.15x

**Discount Percentage:**
- `Discount % = (Market Value - NPV) / Market Value × 100`
- Positive = undervalued (AI value below market)
- Negative = overvalued (AI value above market)

**Note:** Market values are simulated for demo purposes. In production, replace with real market comparable data or appraisal values.

## Regenerating Data

To regenerate the data with different random values:

```bash
# Generate new data
python3 scripts/generate_rrc_data.py

# Verify data quality
python3 scripts/verify_rrc_data.py
```

Note: Data generation uses `random.seed(42)` for reproducibility. Remove or change the seed value for different random data.
